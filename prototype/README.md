# 口播工作台 · 交互原型

静态八步工作台。**推荐同源打开（已接真 API）**：

```
http://127.0.0.1:8787/studio/
```

也可直接打开 `index.html`（需 API 在 8787 且 token 为 `dev-token`）。

## 怎么看

| 想验证的事 | 入口 |
| --- | --- |
| 进料四级降级、失败兜底 | 项目 → 便携榨汁杯 → 第 1 步「进料」 |
| 改一句文案 → 下游全部过期 | 第 3 步「差异化改写」→ 直接改文字 → 保存并标记过期 |
| 重跑到最新（复用缓存） | 顶部黄色提示条 → 「重跑到最新」 |
| 客户审阅页长什么样 | 左侧眼镜图标 → 「客户视角预览」 |
| AI 镜头怎么切厂商 | 第 5 步「AI 补充镜头」→ 每镜可切即梦 / 可灵 / 海螺 / kie |
| 渲染 spec 长什么样 | 第 6 步「成片预览」→ 查看时间线 JSON |
| 客户意见回写、归到哪一步 | 第 8 步「客户交付」卡片 |
| 缺项只补问一项 | 左侧「新建口播单」 |

## 两个入口

- `index.html` — 工作室工作台
- `deliver.html` — 客户审阅页（免登录，可单独打开）

## 交互设计上的三个决定

1. **流程常驻可见**：八步是常驻的横向轨道，不是向导。任何一步都可以随时点开，不用从头走。
2. **过期用「变灰 + 提示条」，不用弹窗**：改稿后下游只是标记，不自动重跑、不自动扣费，由人点「重跑到最新」。
3. **阻断可解释**：质检未通过时不是简单禁用按钮，而是给出「哪一项、为什么、怎么修」，并提供留痕的强制放行。

## 文件

```
index.html      外壳 + 左侧导航
style.css       设计令牌与全部样式
data.js         图标、八步定义、演示项目数据
state.js        全局状态（stale / 队列 / 质检结果 / 表单）
ui.js           toast、弹窗、状态标签等小组件
panels1.js      第 1–3 步面板 + 流水线 + 右侧栏
panels2.js      第 4–8 步面板 + 客户交付卡片 + 工作台外壳 + 全部交互动作
broll.js        AI 补充镜头数据（4 家供应商）+ 视觉质检抽帧
timeline.js     渲染时间线 spec（服务端与桌面端共用）
app.js          路由、项目列表、新建表单、导览
deliver.html    客户审阅页（免登录交付端）
deliver.css     客户页样式
deliver.js      客户页逻辑（逐句留言 / 通过 / 需修改）
```

## 与真实系统的对应

| 原型里的东西 | 真实系统里应该是 |
| --- | --- |
| 八步轨道 / 过期标记 | `artifacts.input_hash` + `stale` 计算 |
| 重跑到最新 | 队列里的单步 job，带缓存命中 |
| 右侧「成本」 | `provider_calls` 按项目聚合 |
| 质检 17 项 | 文本走 DeepSeek、画面走多模态、数值与事实走回溯核对，结果落 `qc_reports` |
| 导出包 8 件 | 按 `artifacts.kind` 装配目录后打包 |
| 强制放行 | `qc_override` 字段 + 审计日志 |
| 客户交付链接 | `deliveries(token, project_id, artifact_version, expires_at)` |
| 客户逐句意见 | `client_comments(cue_id, tc, text, resolved_step)` |

## 已知占位

- **连上 API 时**：项目列表 / 新建 / 八步状态 / 重跑 / SSE / 产物清单 / 成本 / 导出 / 强制放行 走真后端。
- **各步中间面板**多数仍是演示 UI（进料分级、B-roll 按钮等）；口播稿正文在连 API 时尽量从 `script` 产物拉取。
- 未连 API 时仍为假数据，刷新即重置。
